# Quick Start Administrator Guide

Источник: [Quick Start Administrator Guide](https://slurm.schedmd.com/quickstart_admin.html).
Роль: Подготовка. Статус: запланировано, не пройдено.

## Объём

Архитектура служб; конфигурация slurm.conf; аутентификация; регистрация узлов; журналы.

## Критерий завершения

Описать, какие шаги гайда автоматизированы Dockerfile/entrypoint, и проверить службы и узлы.

Это план прохождения, не готовая инструкция с проверенными командами.
Шаги уточнять при чтении документации и выполнять на базовом стенде.
